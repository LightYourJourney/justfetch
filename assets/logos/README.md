# Built-in ASCII artwork

These compact ASCII designs were drawn for justfetch v0.1 as simplified line renderings of the platform emblems they identify. They are distributed under the project GPL-3.0-only license. No artwork file was taken from another fetch tool or from a third-party ASCII-art collection.

The Linux logo is an original line drawing of the Tux penguin motif that identifies Linux. It deliberately is not the long-circulating Tux ASCII art of unknown authorship, which an earlier revision of this directory contained and which was removed during review. If you believe any file here reproduces someone else's work, open an issue and it will be replaced.

Platform names and emblems identify the detected system. No affiliation, sponsorship or endorsement by any operating-system vendor is claimed, and those marks remain their owners' property. This is the project's own provenance statement, not legal advice and not a trademark clearance.

No Nerd Fonts or private-use glyphs are required.
