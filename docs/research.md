## Dependency evaluation

Current stable registry metadata and downloaded manifests checked 2026-10-10. Context7 resolved official sysinfo/clap/unicode-width documentation; pinned sysinfo 0.39.6 source is authoritative when main-branch docs differ (e.g. constructors are infallible in the release, unlike retrieved main examples).

| Dependency | Selected version / MSRV | Purpose |
| --- | --- | --- |
| clap | 4.6.7 / 1.85 | CLI derive; disable default color feature so help obeys plain-output policy |
| sysinfo | 0.39.6 / 1.95 | CPU brand; system feature only (native shell lookup avoids hidden process scans) |
| serde / serde_json | 1.0.229 / 1.56; 1.0.151 / 1.71 | Explicit JSON model, raw numbers |
| unicode-width / unicode-segmentation | 0.2.2 / 1.66; 1.13.3 / 1.85 | Display cells and safe grapheme wrapping |
| anstyle | 1.0.14 / 1.66 | Basic ANSI styling, no TUI framework |
| libc / windows-sys | 0.2.190 / 1.65; 0.61.2 / 1.71 | Narrow native adapters, terminal size queries |

All selected crates are MIT or MIT/Apache-2.0 compatible with the repository's existing GPLv3. Cargo.lock records exact transitive versions; [third-party.md](third-party.md) includes their declared licenses and Unicode notices. sysinfo default disk/network/user/component features and multithread support are disabled. TOML 1.1.8 was evaluated, omitted from v0.1 for want of a configuration file, and adopted in v0.2 when one was added; it declares Rust 1.85, so it does not move the MSRV floor. thiserror 2.0.21, anyhow 1.0.104, assert_cmd 2.2.2 and insta 1.49.0 remain omitted: small structured errors suffice and standard-library process tests avoid extra test dependencies. terminal_size 0.4.4/crossterm were unnecessary for one read-only size query. The pinned macOS/Windows process adapter enumerates all PIDs even for selected updates; justfetch uses direct Unix parent queries and one Windows ToolHelp snapshot instead. Windows CPU count uses all processor groups rather than the dependency list length. See architecture.md for alternatives and compatibility.md for precise memory semantics.

## Licensing and names

The existing GPLv3 LICENSE is retained (GPL-3.0-only in Cargo metadata), rather than silently relicensing to MIT. Reference repository licenses do not prove provenance of every bundled ASCII resource. Every included justfetch logo is newly authored ASCII; names identify detected platforms and do not imply vendor endorsement. No third-party implementation/assets are vendored.

GitHub name search returned seven existing repositories named justfetch, including vars1ty/JustFetch and everitosan/justfetch. The name is not globally unique. The configured project remote is LightYourJourney/justfetch and is preserved. Cargo sparse index path `ju/st/justfetch` returned 404; this is a point-in-time check, not a name reservation. Homebrew core Formula/j/justfetch.rb and Scoop Main bucket/justfetch.json returned 404; other taps/buckets and winget were not exhaustively searched. Recheck availability before publication; no renaming or publication performed.

## Verification boundaries

No upstream project tests were rerun and Issue reports were not reproduced. Installed competitor execution, if measured, is recorded separately in performance.md. No comprehensive upstream security/license audit or trademark clearance is claimed. Linux, Windows and WSL hardware claims for justfetch must be scoped to the evidence in compatibility.md; CI configuration alone does not establish execution.

Primary platform references: [os-release specification](https://www.freedesktop.org/software/systemd/man/latest/os-release.html), [Linux proc documentation](https://docs.kernel.org/filesystems/proc.html), [Microsoft WSL architectures](https://learn.microsoft.com/en-us/windows/wsl/compare-versions), [GlobalMemoryStatusEx](https://learn.microsoft.com/en-us/windows/win32/api/sysinfoapi/nf-sysinfoapi-globalmemorystatusex), [Apple XNU memory definitions](https://github.com/apple-oss-distributions/xnu/blob/main/doc/vm/memorystatus_notify.md). The freedesktop page returned 403 in the web tool; parsers are tested directly and the source is not claimed to have been fetched successfully.
